# mitmproxy — Free Offline Installer

![Category](https://img.shields.io/badge/HTTP_Proxy-blue?style=flat-square)

## About

mitmproxy is a free, open-source interactive HTTPS proxy for Windows, macOS, and Linux. Intercept, inspect, modify, and replay HTTP/HTTPS traffic through a command-line interface, terminal UI, or web interface. mitmproxy's scriptable interface using Python enables automation of request inspection and modification. Essential for security testing, API debugging, and mobile app traffic analysis.

## Common Problems & Limitations

- **Technical Complexity** — Command-line primary interface requires comfort with terminal
- **Certificate Trust** — Client certificate installation required for HTTPS interception
- **SSL Pinning** — Apps with certificate pinning require additional bypass techniques
- **GUI Option** — Web interface less capable than dedicated HTTP proxy GUI tools
